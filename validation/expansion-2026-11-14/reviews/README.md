# Independent source-review snapshots

- [Dragon source snapshot](dragon-independent-review-2026-11-14.json): every line of 24 scoped dragon, new forging/client, recipe-viewer, and related mixin files, totaling 696 physical lines. Paths, ranges, hashes, confirmed findings, and native comparison topics are recorded. This does not claim a manual review of all 276 Java files in the automated inventory.
- [Health/controller peer snapshot](dragon-health-controller-peer-review.json): a separate bounded review of the maximum-health correction and graphical dragon controller. Its per-file scope distinguishes whole-file reads from a reviewed helper only.

These files preserve their review-time status and findings. Later fixes and completed runtime results are described in [the dated findings](../../../docs/REVIEW_FINDINGS_2026-11-14.md) and [graphical gallery](../index.html). A pending disposition in a snapshot is not the current release verdict.

The underlying local native Minecraft bytecode comparisons remain private development references and are not copied into this repository evidence directory.
