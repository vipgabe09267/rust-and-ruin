# Rust & Ruin: fresh full audit, October 23, 2026

This is a new manual review of the current project after the 24-request refresh. It found and fixed **17 reproduced defects**, added 20 server regressions/boundary checks, strengthened two existing tests, and expanded the graphical client regressions. Version remains **0.1.0-beta**. The audit itself did not commit or push. The owner subsequently authorized a local commit on October 24 while continuing playtesting; no push is included.

## What was read

All **193 executable project files, 10,632 lines** were read in fresh numbered views: every production Java class and mixin, every GameTest and client-test class, all checked-in PowerShell/C# generators and auditors, Gradle configuration, and both wrapper scripts. Every final edited code file was reread. The [per-file manifest](../validation/reaudit-2026-10-23/line-review.json) records current hashes, complete line ranges and the read receipts; the [change inventory](../validation/reaudit-2026-10-23/changed-code.json) identifies 28 code files changed by this audit relative to its starting snapshot.

The numbered read transcripts and native Minecraft bytecode inspections are retained locally in `.tools/reaudit-2026-10-23/`. Reading coverage is a record of the review, not a mathematical proof that code is correct. Generated JSON and binary assets received generator review plus format, reference, runtime, regeneration and package validation; this is not a claim of manually reading every line of every generated data file or old validation log.

## Reproduced defects and fixes

Severity here describes gameplay impact, not a CVE score.

| ID | Impact and trigger | Fix and evidence |
| --- | --- | --- |

| R2 | Medium: an already-running skeleton nail goal could fire after its target entered Creative. | Recheck the complete target/weapon predicate before acting. Regression revokes a real Survival player's eligibility. |
| R3 | Low: mutation reduced a customized creeper explosion radius of 9 to 4. | Treat 4 as a minimum, retaining larger existing radii on conversion and reload. |
| R4 | Low: a dropped item's final coating-expiry tick could remove its NBT without marking its tracked stack dirty. | Synchronize on final expiration as well as the regular cadence. DataTracker regression checks the off-cadence final tick. |
| R5 | Medium: caltrops and barbed wire could hurt a creature above their physical shape. | Require contact with their actual outline bounds. Tests cover jumping above caltrops and positive surface contact. |
| R6 | Medium: a bear trap could close on a creature above its jaws. | Apply the physical-contact check to bear traps, with a tiny surface-contact tolerance. Both aerial and positive surface cases checked. |
| R7 | Low: upgrading a legacy cabinet at the world ceiling marked it complete without an upper half. | Check build-height headroom before migration. Regression preserves and restores the ceiling fixture. |

| R11 | Low: custom medicines omitted native item-use statistics and the consume-item advancement trigger. | Record native consumption for antitoxin and both disease-vaccine/tonic paths. All four medicine statistics checked. |
| R12 | Low: removing or breaking gloves while a chest was open left client rendering using a stale inventory fallback. | Always use authoritative tracked glove state on clients, including EMPTY. Reproduced and verified in the graphical client with an open container. |
| R13 | Low: the field guide rounded the 0.5% default mutation rate to 1%. | Preserve fractional percentages. Real client assertion checks the connected server's default rate. |

## Additional review work

- Client config, symptom and disease-presence callbacks now verify their originating network handler inside the scheduled task. This prevents an old connection's queued work from changing a later session. This is reviewed defensive hardening; no live server-switch exploit reproduction is claimed.
- The doMobLoot regression now kills a permanently mutated animal; its old fixture used only temporary illness and missed the variant override. The legacy-tool probability test now uses a fixed seed.
- Suspected standalone Lockjaw advancement, infinite Salmonella and movement-angle failures were ruled out through native code and runtime checks. They are not counted as fixes. Initial Creative-mock and effect-refresh fixture mistakes were corrected before drawing production conclusions.
- Security checks cover bounded malformed payload parsing, operator permissions, finite positions, Creative glove authorization, server-side beacon payment/tier validation, and inventory/recipe accounting. No new arbitrary C2S payload or mandatory dependency was added. This is not an independent current-CVE scan of every upstream library.
