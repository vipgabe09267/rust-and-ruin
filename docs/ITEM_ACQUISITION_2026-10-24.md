# Item acquisition inventory - October 24, 2026

This inventory distinguishes craftable items from weathering, brewing, loot and trade rewards. Spawn eggs and the five retired iron tools intentionally have no Survival crafting recipes. The field medic cabinet is a structure-only block without a separate inventory item; breaking it yields the ordinary cabinet.

The release tests enumerate the actual item registry and reject any item without an explicit route. Native crafting/cooking/smithing tests cover recipe outputs; acquisition tests additionally execute the native brewing stand, all nine weathering conversions, brush byproducts, animal and boss death loot, cow collection, native merchant transactions, and every variant spawn egg. Passing results must come from the test run; this table alone does not establish a pass.

## Test limits

Creative setup supplies ingredients and test fixtures. Outputs are obtained from production game logic: recipe handlers, brewing-stand ticks, death loot and paid merchant output slots. Conditional loot uses fixed seeds; the hook boundary test invokes the production salvage operation with a successful 15% roll, while the existing timed-water test separately verifies that rods naturally reach salvage. These are repeatable runtime regressions, not a substitute for an extended human Survival playthrough.
