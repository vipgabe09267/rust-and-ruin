## Findings fixed during implementation and review

- Old clinic house-pool weights did not express a per-village chance or provide native locate support. Replaced with a village-aligned native structure grid, and removed the old pool injection to avoid duplicate generation paths.
- All clinic medics previously used the same biome identity. Added correct identities and material palettes, including Minecraft's `snow` villager type for snowy villages.
- The first cabinet migration skipped old blocks because Minecraft Boolean properties default to true. Explicitly default migration state to false; new item/template placements mark complete pairs. Pair placement preserves neighbor validation, and a blocked ceiling remains untouched.
- Assigning weapons in the base MobEntity initialization occurred before Minecraft assigned subclass equipment. Moved skeleton/zombie assignment after their native initialization. A regression executes the complete spawn path on 512 skeletons and 512 zombies.
- Extra skeleton attack goals could accumulate or disappear on reload. Refresh now removes duplicate nail goals and selects the correct ranged behavior; native bow behavior returns when appropriate.
- The old arrow art filled a rectangular region outside the native UV silhouette, creating giant opaque planes. Its alpha now exactly matches a native arrow.
- Native Mending only considers vanilla equipment slots. Include the dedicated glove slot fairly alongside other damaged enchanted equipment, without converting the item into an offhand item.
- Several advancements were earned behind an undiscovered root, making them appear absent in Creative testing. Custom awards now reveal the root. Protected-shield detection also recognizes ordinary rusty attacks.
- Raw meat effects conflicted with the requested diseases. Separate raw Infected Meat from metal-caused Tetanus and give raw Rabid Meat immediate sickness feedback.
- Vaccine rolls could make operator /effect commands appear broken. Bypass prevention only for the permission-checked command path; restore the context even on exceptions.
- Earlier smoke screenshots selected off-page Creative tabs directly, so Fabric canceled the selection. The updated harness navigates the actual pages and checks both the dedicated inventory slot and tracked glove state. Cabinet screenshots also needed a floor under the test camera; corrected the fixture.
- Updated stale tests and public documentation that still expected the former high mutation rates or raw-meat Tetanus. Existing unrelated regressions remain enabled.

## Owner testing limits

Structures require new terrain and suitable space. The 55% clinic and 15% camp values are candidate rolls, not promises that every counted village or cave contains a medic. Camps are deliberately widely spaced. Existing villages are not retrofitted.

Test in a backed-up survival world and on your actual multiplayer server before release. The automated suite exercises disease, inventory, recipe, AI, despawn and structure paths, but does not exhaust every seed, terrain layout, client skin, multiplayer latency or third-party mod combination. The local integrated-client runs do not constitute a remote two-client server play session. Native locate registration/generation are checked; unlimited exploration searches across arbitrary seeds are not exhaustively tested.
