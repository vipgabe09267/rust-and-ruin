# Replacement item art - October 23, 2026

Created with the built-in image_gen tool and copied into this repository. No API key or CLI generation was used. These four PNGs are the retained full-size sources; tools/Generate-Refresh.ps1 imports them as transparent 64x64 game sprites with clear margins. The user requested replacement of the existing sprites.

Design briefs (recorded descriptions, not verbatim tool-call logs):

- veterinary_kit.png: compact leather veterinary satchel, visible medicine vials, metal clasps and a readable medical emblem; isolated Minecraft-compatible pixel-game object, no lettering or scene.
- iron_spear.png: long wooden shaft, wrapped grip, forged steel spearhead and reinforced collar; one readable diagonal weapon silhouette, transparent background.
- rusted_iron_spear.png: edit of the clean spear preserving shaft, silhouette, scale and grip; add pitted reddish corrosion to the steel head and fittings.
- trap_reset_tool.png: practical forged trap-setting tongs with paired jaws, pivot, worn handles and convincing metal highlights; isolated diagonal tool, transparent background.

The medic palettes, glove materials, cabinet geometry, and native-layout arrow recolor are generated deterministically by the resource scripts. They were not submitted as additional image generation calls.
