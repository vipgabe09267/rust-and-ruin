# Expansion artwork

The new expansion sprites and medical clothing are drawn by `tools/Draw-Expansion-Art.ps1` using explicit pixel shapes, outlines, highlights, and a shared metal/rust palette. Spear, reset tool, vial, meat, status, heart, cabinet, and rusty block outputs are generated directly, without slicing an atlas. Item/status sprites leave transparent margins.

The bear trap, barbed wire, and Rust pile are Minecraft block models generated by `tools/Generate-Expansion.ps1`, using the existing metal/material textures. The clinic is a native block structure generated by `tools/Generate-Clinic.ps1`.

Creature variants preserve original species UV layouts. Tetanized skins add rust discoloration; rabid skins use desaturated coloring, pale highlights, and clustered red sores. Generated textures are cached separately and released on resource reload. The existing artwork elsewhere in this directory retains its original provenance in the associated PROMPTS files.
